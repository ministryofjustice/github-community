Create a chart

Choose New chart, enter a Chart name and select a Layout. With Chart data set to Custom chart, choose:

  • Category / axis: what to organise results by, such as Team, Sprint or Status.
  • Measure: what to calculate, such as Count of items or Sum of Estimation.
  • Group by: an optional way to split results into separate series.

Other settings appear when needed. The preview updates as you make changes. Nothing is saved until you select Save.

To start from an existing chart, open Configure and choose Edit as Custom recipe. Your saved chart stays unchanged until you save. If choices cannot be used together, a message explains what to change.

Filter data

Use Filter by keyword or field above the chart. Choose suggestions or type filters, such as team:Blueprint status:"In Progress". Use quotes around values with spaces. You can also enter a keyword to search item titles.

Date filters

On time-axis charts, open Filter by keyword or field → Date range. Choose 2 weeks, 1 month, 3 months, Max or Custom range to enter From and To dates. You can also type from:2026-09-14 to:2026-09-27.

Presets end at the latest available date and stay within recorded history. Max removes date restrictions.

Filters apply to the active chart and use Save and Discard. Use dates and values available in your workspace. Remove date filters to show all history, or clear the search box to remove all search filters.

Understanding the results

Planned and unplanned work uses the board's Planned field. It does not show what was agreed at the start of a sprint or what changed later. Those are shown by separate calculations, such as Sprint-start commitment and Sprint churn.

Estimation uses the numbers entered on the board, without treating them as hours, days or story points. Sums and averages include zero but leave out missing values.

Some charts need recorded history. If that history is missing, the chart shows that the calculation is unavailable.

Save and delete

  • Save updates the shared chart for everyone with workspace access.
  • Save as new creates a separate chart.
  • Discard removes unsaved changes and restores the saved chart.

Save and Discard are disabled when nothing has changed.

Delete chart asks for confirmation before removing the shared chart. It does not delete GitHub items or their underlying data.

Data table and item drill-down

Select Data table for exact values. Select an item count or chart point to see the items behind it. Changing pages does not change the results.

Item axes use short references such as #511. When numbers clash, those labels include the repository name, such as developer-experience#115. Tooltips, tables, details and CSV keep the full reference.

GitHub links open the issue or pull request. Other references are text only.

Sprint churn may count the same item more than once if it is added or removed several times.

Export CSV

Select Export CSV to download every row, not just the page shown. The file includes filters, exact values, item references and data sources.

You cannot export when there are no rows or the calculation is unavailable.
